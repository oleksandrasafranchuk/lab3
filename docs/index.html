Етапи роботи

  
    
    
  1. Лексичний аналіз (Flex, lexer.l): текст розбивається на токени — ключові слова, ідентифікатори, числа, оператори.
    2. 
    
  2. Синтаксичний аналіз (Bison, parser.y): LALR(1)-парсер перевіряє програму за граматикою C і будує AST.
    3. 
    
  3. Семантичний аналіз (sema.c): області видимості, типи, кількість аргументів, lvalue, break поза циклом.
    4. 
    
  4. Виконання (interp.c): інтерпретатор обходить AST і обчислює програму.
    5. 
    
  5. Генерація коду (codegen.c): з AST будується еквівалентна програма на Python.
    6.
